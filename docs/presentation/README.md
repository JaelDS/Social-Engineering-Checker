## Open and present

**For tomorrow's presentation, open [the PDF deck](checkfirst-pitch.pdf).** It contains 11 slides and can be presented offline in a PDF viewer's full-screen mode.

For slide navigation and speaker notes, open [checkfirst-pitch.html](checkfirst-pitch.html) in a current browser. It contains all styles and scripts locally, needs no internet connection, and does not load external fonts, images or analytics.

- Use **Next** and **Previous**, the arrow keys or Page Up / Page Down.
- Use **Home** and **End** for the first and last slides.
- Use **Overview** or **O** to see the complete deck.
- Use **Notes** to show presenter notes in overview mode.
- Use **Full screen**, or the browser's own full-screen command.
- Use **Print** to print all 11 slides. Choose landscape, enable background graphics and turn off browser headers and footers if your browser offers those options. The deck requests a 16:9 paper size.

Presentation controls are excluded from print. If JavaScript is disabled, all slides remain readable in order. On a narrow screen the content reflows and longer slides can be scrolled.
