## Read in Obsidian

Open this project folder, or its `docs` folder, as an Obsidian vault. These files use Markdown tables, YAML properties, callouts, a Mermaid diagram, small HTML panels and expandable details. No community plugin or remote embed is required. Switch to Reading view to see the rendered layout; Source mode exposes the underlying text for editing. Relative links connect the documents, while the fictional email fixture link reaches outside `docs` into the application folder.

Keep any private university notes, account identifiers, credentials or real submissions outside this source repository. Use the single **Ordered owner handoff** in [SETUP.md](SETUP.md#ordered-owner-handoff) when you are ready to connect accounts.
